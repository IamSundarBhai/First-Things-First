# First Things First

**First Things First** is an open-source productivity and task management platform designed to help users focus on what matters most.

This project is not just a simple ToDo application. It is a complete productivity system built to help users capture tasks, prioritize work, plan their day, track goals, build habits, and improve productivity with intelligent insights.

> Focus on what matters most.

---

## Project Vision

Most task management applications help users store tasks.

**First Things First** aims to go one step further by helping users answer an important question:

> What should I work on first?

The goal of this project is to build a modern productivity platform that combines task management, prioritization, planning, analytics, and AI-assisted productivity features across both web and mobile applications.

## Core Features

### Task Management

* Create, update, delete, and complete tasks
* Add due dates and reminders
* Set task priorities
* Add descriptions and notes
* Track task status
* Organize tasks with tags and categories

### My Day Planner

* Plan daily work
* View today’s important tasks
* Add or remove tasks from the daily plan
* Track daily completion progress

### Smart Prioritization

* Prioritize tasks based on importance and urgency
* Support priority scoring
* Recommend what to work on first
* Support Eisenhower Matrix-style planning

### Projects

* Create and manage projects
* Group related tasks
* Track project progress
* Manage project milestones

### Goals and OKRs

* Define long-term goals
* Add measurable key results
* Link tasks to goals
* Track progress over time

### Habit Tracking

* Create daily or weekly habits
* Track habit streaks
* View habit completion history
* Build consistency over time

### Calendar and Time Blocking

* View tasks in calendar format
* Plan work by day, week, or month
* Schedule focused work blocks
* Manage upcoming deadlines

### Reminders and Notifications

* Task reminders
* Due date alerts
* Habit reminders
* Daily planning notifications
* Weekly review reminders

### Notes and Attachments

* Add notes to tasks and projects
* Attach files and documents
* Store supporting information in one place

### Analytics and Insights

* Track completed tasks
* View productivity trends
* Monitor overdue tasks
* Analyze project progress
* Review weekly and monthly productivity

### AI Productivity Assistant

Planned AI features include:

* Natural language task creation
* AI-based task prioritization
* Task breakdown suggestions
* Daily planning assistance
* Weekly productivity summary
* Goal alignment suggestions
